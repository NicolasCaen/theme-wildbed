## 🎨 Modèles de page

Les modèles de page sont des patterns WordPress qui structurent le contenu des différentes pages du site.

### Modèle Accueil (`modele-page-home`)
**Slug:** `ng1-base/modele-page-home`  
**Description:** Modèle pour la page Accueil

**Sections incluses:**
- Banner home avec recherche
- Section texte multi-images
- Section carousel hébergement
- Section liens 3 colonnes
- Section "Pourquoi"
- Section media-texte avec background 6
- Section labels

### Modèle Camping (`modele-camping`)
**Slug:** `ng1-base/modele-camping`  
**Description:** Modèle pour les pages Camping

**Sections incluses:**
- Section banner with images
- Section media-texte
- Section slider
- Section media-texte avec background (variantes 1, 2, 3)
- Section media-texte reverse

### Modèle Hébergements (`modele-hebergements`)
**Slug:** `ng1-base/modele-hebergements`  
**Description:** Modèle pour la page Hébergements

**Sections incluses:**
- Section banner with images B
- Section media-texte avec background 4 (avec shortcode [ctv_product_list])
- Section media-texte avec background 5 (avec shortcode [ctv_product_list])
- Section plan

### Modèle Infos Pratiques (`modele-infos-pratiques`)
**Slug:** `ng1-base/modele-infos-pratiques`  
**Description:** Modèle pour les pages Infos Pratiques

**Sections incluses:**
- Section banner texte
- Section bento 2-2-1
- Section list ultrawide
- Section bento 6-3-2
- Section bento 3-33-66
- Section FAQ
- Section bento contact (avec formulaire Contact Form 7)

### Modèle Tarifs & Offres (`modele-tarifs-offres`)
**Slug:** `ng1-base/modele-tarifs-offres`  
**Description:** Modèle pour les pages Tarifs & Offres

**Sections incluses:**
- Section banner texte
- Section bento information
- Section offres spéciales (avec shortcode [ctv_calendar])
- Section disponibilités (avec shortcode [ctv_calendar])
- Section texte ultrawide
- Section bento 2 colonnes
- Section labels
- Section CTA bon cadeau

## �📌 Shortcodes

Le thème utilise les shortcodes suivants (généralement fournis par des plugins tiers):

### `[ctv_search]`
**Utilisation:** Recherche d'hébergements  
**Exemple:** `banner-home.php`

### `[ctv_product_list type="accommodation"]`
**Utilisation:** Affichage de la liste des produits hébergements  
**Exemples:** 
- `section-media-texte-with-bg-4.php`
- `section-media-texte-with-bg-5.php`

### `[ctv_calendar product_id="94258"]`
**Utilisation:** Calendrier de disponibilités  
**Exemples:**
- `section-disponibilites.php`
- `section-offres-speciales.php`

### `[contact-form-7 id="6a81bf9" title="Formulaire de contact 1"]`
**Utilisation:** Formulaire de contact  
**Exemple:** `section-bento-contact.php`

## 🎭 Styles de blocs

Styles personnalisés pour les blocs WordPress.

### Core Group Styles

#### `is-style-panneau`
**Blocs concernés:** core/paragraph, core/heading, core/post-terms  
**Description:** Style panneau avec fond contrast (orange) et texte blanc

**Caractéristiques:**
- Fond: `var(--wp--preset--color--contrast)`
- Texte: `var(--wp--preset--color--accent-2)`
- Border radius: 0.5rem
- Padding: 0.75rem vertical, horizontal basé sur spacing h-24
- Font size: 44px
- Largeur: fit-content
- Centré horizontalement

#### `is-style-panneau-rotated`
**Blocs concernés:** core/paragraph, core/heading, core/post-terms, core/query-title  
**Description:** Style panneau avec rotation -3.315deg

**Caractéristiques:**
- Même base que `is-style-panneau`
- Rotation: -3.315deg
- Font family: Titan One
- Font size: 1.5rem
- Liens héritent la couleur du texte

#### `is-style-decal-50-percent`
**Description:** Décalage de 50%

#### `is-style-one-row-grid`
**Description:** Grid sur une ligne

- xs: 13px (extra small)

## 📝 Notes

- Les shortcodes `[ctv_*]` sont fournis par un plugin tiers (probablement un plugin de réservation/hébergement)
- Le formulaire Contact Form 7 est géré par le plugin Contact Form 7
- Les styles de blocs utilisent le système de variations de WordPress (theme.json)
- Les classes utilitaires sont générées automatiquement depuis le theme.json ou définies manuellement en SCSS
